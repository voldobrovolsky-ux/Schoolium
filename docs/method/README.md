# Метод EduStore — спека как продукт конвейера, а не как текст

> Назначение: превратить «напиши спеку на X» из письменной работы в **прогон
> конвейера с воротами**. Владелец задаёт вектор одной фразой («нужен журнал»),
> агент добывает внешний базис, проецирует его на продуктовую логику, фиксирует
> решения, пишет спеку, **строит пробное окружение и ломает свою же спеку до
> того, как написана первая строка продакшн-кода**, и возвращает уже
> исправленный документ с приложенным доказательством.

## Три несущих правила

1. **Утверждение принимается только со свидетельством.** «Проверено ✓» без
   перечисления (матрица, скрипт, прогон стенда) — это заявление. Оно
   вычёркивается как находка. Наследуется из `G-CHECKS.md` и распространяется
   на спеки: раздел без матрицы полноты не готов к передаче.
2. **Дыры ищутся до кода и дешевле кода.** Порядок стоимости находки:
   T0 линт (секунды) → T1 матрицы (минуты) → T2 исполняемая модель (десятки минут)
   → T3 стенд на рантайме (часы) → прод (недели + доверие школы). Спека не идёт
   на следующий уровень, пока предыдущий красный.
3. **Линза рождается из протечки, а не из идеи.** Новый угол проверки заводится
   тогда, когда мимо всех действующих линз прошёл конкретный дефект — и к заявке
   приложен этот дефект как свидетель. Иначе набор линз превращается в ритуал.

## Связь с существующими артефактами

- `docs/ar/` — блочные АР-реестры (сквозная нумерация, см. AR-PROTOCOL).
- `docs/G-CHECKS.md` — исполняемые доказательства инвариантов; в терминах
  эволюционной архитектуры это **фитнес-функции** (atomic/triggered).
- `docs/FSM-MATRIX.md` — матрицы полноты; детектор линз L-2 и L-3.
- Скиллы `discovery → architecture → spec → review` — ручные режимы тех же
  стадий конвейера. Конвейер их не заменяет, а расставляет по стадиям и
  добавляет ворота между ними.

## Машинная часть

```bash
npm run method:lint      # все проверки метода
node tools/method/lint-ar.mjs        # реестры: нумерация, диапазоны, ворота, ссылки
node tools/method/lint-lenses.mjs    # линзы: паспорта, покрытие чек-листа
node tools/method/spec-lint.mjs      # спеки: параметры P1…P7
node tools/method/lint-screens.mjs   # экраны и адаптация против спеки
node tools/method/lint-agents.mjs    # инструкции агентов против конвейера
```
