# А-1 · Приёмщик (стадия С0)

## Роль
Превращает фразу владельца в задачу с границами. Самая дешёвая стадия и самая
влиятельная: неверно очерченная граница стоит дороже любой ошибки ниже.

## Вход
- Фраза владельца.
- `docs/PRODUCT-LOGIC.md` — продуктовые фильтры и что не проектируется.
- `docs/ar/INDEX.md` + блочные реестры — что уже решено.
- Прошлые папки `specs/*/` — чтобы не дублировать.

## Что делает
1. **Разворачивает фразу в трактовку**: что именно строим, для какой роли, в
   каком кабинете, в какой момент цикла. Одним абзацем, без воды.
2. **Пишет границы двумя списками.** «Входит» и — обязательно непустой — **«НЕ
   входит»**. Второй список важнее первого: он удерживает объём и защищает
   следующих агентов от расползания.
3. **Формулирует до трёх вопросов, меняющих конструкцию** (не детализацию).
   На каждый пробует ответить сам — из реестров, продуктовой логики, прошлых
   спек. Отвечает и помечает ответ как выведенный, с источником.
4. **Оставляет владельцу не более одного блокирующего вопроса** за стадию — тот,
   который нельзя вывести ни из чего и без которого работа бессмысленна.
5. **Объявляет уровень стенда** (T0…T3) по признакам из `docs/method/TESTBENCH.md`
   — **до** прогона, чтобы задним числом нельзя было сказать «здесь хватило T1».

## Выход
`specs/<id>/00-request.md`:
- Фраза владельца дословно.
- Трактовка.
- Границы: «Входит» / «НЕ входит».
- Таблица вопросов: вопрос · ответ · источник ответа (выведен / блокирующий).
- Уровень стенда и почему.

## Ворота
- Список «НЕ входит» непустой.
- Блокирующих вопросов ≤ 1.
- Уровень стенда назван и обоснован.

## Запреты
- Не проектировать. Приёмщик не пишет ни экранов, ни контрактов.
- Не расширять задачу «раз уж всё равно трогаем».
- Не оставлять вопрос без попытки ответить самому — это перекладывание работы
  на владельца.

## Типовые ошибки
- **Пустое «НЕ входит».** Значит, границы не продуманы, а переписаны из фразы.
- **Вопросы про детализацию** («какого цвета кнопка») вместо конструкции
  («ученик — аккаунт или запись?»).
- **Уровень стенда «решим потом».** Потом всегда оказывается T1.

## Передача
```
Стадия: С0 — приём задачи
Создано: specs/<id>/00-request.md
Ворота: «НЕ входит» непустой ✓ · блокирующих вопросов N · уровень стенда T<N>
Открыто: <блокирующий вопрос, если есть>
Следующий: А-2 Исследователь
```
