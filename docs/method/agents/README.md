# Инструкции агентов конвейера

> Конвейер `docs/method/PIPELINE.md` описывает **стадии**. Здесь — **исполнители**:
> по одной инструкции на агента, с точными входами, действиями, выходами,
> воротами и запретами. Инструкция самодостаточна: агент, получивший только её и
> ссылку на репозиторий, выполняет свою стадию без дополнительных объяснений.

## Три правила, общие для всех

1. **Не додумывай.** Не хватает информации — это `[узел]` или вопрос владельцу,
   а не место для догадки. Угадывание намерения — тот же дефект, что и
   угадывание в коде, только дороже: оно попадёт в спеку и размножится.
2. **Утверждение только со свидетельством.** «Проверено», «покрыто», «готово»
   принимается лишь со ссылкой на перечисление: матрицу, скрипт, прогон.
   Заявление без свидетельства — находка, а не факт.
3. **Не выходи за свою стадию.** Исследователь не принимает решений, Архитектор
   не пишет спеку, Спекрайтер не проектирует контракты внешних систем.
   Пересечение границ агентов — главный источник тихих противоречий.

## Формат передачи

Каждый агент заканчивает работу **паспортом передачи** — блоком в конце своего
выхода:

```
## Передача
Стадия: С<N> — <название>
Создано/изменено: <точные пути>
Ворота: <команды и их статус>
Открыто: <узлы, вопросы владельцу, слоты>
Следующий: А-<N> <имя>
```

Агент, получивший работу без паспорта, **не начинает** — запрашивает его.
Паспорт — не формальность: это единственное место, где видно, что предыдущий
агент оставил незакрытым.

## Схема прохода

```
владелец → А-1 → А-2 → А-3 → А-4 → А-5 → А-6 → А-7 → А-8 ⇄ А-4/А-5 → А-9 → А-10 → А-11
                                                        ↑ цикл до зелёного
```

Возврат от А-8 (стенд) и А-9 (линзы) идёт **в А-4 или А-5**, а не в «список
замечаний». Замечание, не превратившееся в правку решения или текста, — это
несданная работа.

## Ворота набора инструкций
`node tools/method/lint-agents.mjs` (G-40) — каждая стадия конвейера имеет
агента, каждая инструкция содержит обязательные разделы, каждый ссылается на
существующие файлы.
