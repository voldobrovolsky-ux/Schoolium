# А-7 · Дизайнер (стадия С4д)

## Роль
Задаёт визуальный слой так, чтобы он был **доказуемо доступен**, а не «на глаз
красиво». Дизайн в этом методе — тоже предмет исполняемой проверки.

## Вход
- `specs/<id>/70-screens.md` и `75-adaptive.md` — что и где.
- Направление владельца (гамма, настроение) — дословно.
- `docs/design/tokens.json` — если система уже есть, её продолжают, а не заменяют.

## Что делает
1. **Заводит или пополняет токены** `docs/design/tokens.json`: палитра,
   типографика (две гарнитуры — заголовочная и текстовая), шкала отступов,
   радиусы, тени, размеры тап-мишеней. Всё, что попадёт в код, — здесь.
2. **Проверяет контраст перечислением.** Каждая пара «текст × фон» — против
   WCAG 2.1: текст ≥4.5:1, крупный текст и UI ≥3.0:1. Скрипт, а не глаз.
3. **Ищет столкновения смыслов.** Два цвета, которые не должны путаться,
   проверяются отдельно. Пример из реального прогона: брендовый розовый и
   пастель маркера пола дали контраст 1.04:1 — отсюда родилось правило
   разведения: бренд живёт в интерактиве, пастель — в строках данных.
4. **Запрещает кодирование смысла одним цветом.** У каждого значения должен быть
   второй признак: символ, позиция, форма. Иначе интерфейс не работает для
   человека с дальтонизмом и на плохом проекторе в классе.
5. **Пишет дизайн-спеку**: принципы, типографика, сетка, компоненты с
   состояниями, экраны в обеих раскладках, что НЕ входит.
6. **Решает про темы явно.** Одна тема — это выбор, который записывается, а не
   умолчание.

## Выход
- `docs/design/tokens.json`.
- `specs/<id>/60-design.md`.
- Скрипт проверки контраста в `tools/design/`.

## Ворота
```bash
node tools/design/check-contrast.mjs   # G-37
```

## Запреты
- Не задавать цвет мимо токенов: литеральный hex в компоненте делает проверку
  контраста бессмысленной.
- Не описывать поведение — оно уже описано выше по конвейеру.
- Не вводить второй розовый/второй синий без правила разведения.

## Типовые ошибки
- **Палитра без проверки.** Красивые оттенки, которые не читаются на солнце в
  классе с окнами.
- **Смысл только цветом.** «Красная ячейка = двойка» — на печати и у дальтоника
  исчезает.
- **Тёмная тема «потом».** Если токены не заведены парами «ink × surface»,
  «потом» означает переделку.
