# ADR 0002 — Журнал: позиционирование под 273-ФЗ ст.16 ч.3.1

**Статус:** принято · **Дата:** 2026-06

## Контекст
С 01.01.2023 при реализации основной общеобразовательной программы с ЭО/ДОТ и
обработкой ПД учеников школа обязана использовать государственную ИС (ФГИС «Моя
школа» + региональный журнал, в Приморье — «Сетевой город»). Коммерческая LMS не
может быть системой-источником официального журнала в госшколе.

## Решение
Журнал EduStore работает в двух режимах:
- **Частные школы** — полноценный журнал (официальная запись), ограничения нет.
- **Государственные школы** — рабочий слой с синхронизацией оценок в гос-ГИС;
  основная продажа — не-журнальные модули «зелёной зоны» (расписание, кабинеты,
  предиктив, портал, контент), которым не нужно быть системой записи.

Голосовой ввод проектируется как «надиктовал → запись», источник синка —
агностичен (локальный журнал частной школы или гос-ГИС).

## Последствия
+ Юридически чистый заход в госшколы; первый клиент (частная школа) — без ограничений.
+ Killer-фичи лежат в зелёной зоне, где гос-стек слаб.
− Для госшкол нужна интеграция-коннектор к гос-ГИС (анти-коррупционный слой) — отложена.
− Монетизация родительского портала: питание/студии — да; **оценки/ДЗ — никогда не
  paywall** (ADR-следствие из тренда Госдумы 12.2025 против платных дневников).
