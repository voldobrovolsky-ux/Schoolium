# ADR — архитектурные решения (легаси-формат)

Ранние решения репозитория в формате ADR (контекст → решение → последствия).
С 2026-08-19 новые архитектурные решения ведутся в блочных АР-реестрах
[docs/ar/](../ar/INDEX.md) со сквозной нумерацией `AR-N` — см.
[docs/method/AR-PROTOCOL.md](../method/AR-PROTOCOL.md). Файлы ниже не
переносятся туда задним числом и остаются как есть — это принятая история,
не текущий процесс.
