# Выбор библиотеки компонентов: замеры

Решение — [AR-197](../../ar/ui.md). Здесь — данные, на которых оно принято.
Замер выполнен зондом [`tools/design/lib-probe`](../../../tools/design/lib-probe/README.md)
2026-09-03: шесть приложений одного смысла на стеке Schoolium (React 18.3.1,
Vite 5.4.21), `vite build`, размер ассетов raw и `gzip -9`.

## 1. Размер бандла

Дельта считается к варианту `base` — то же приложение без библиотеки (React-пол
46,6 КБ gzip JS).

| Вариант | Состав | JS gzip | Δ JS gzip | CSS gzip (raw) |
|---|---|---|---|---|
| `base` | React 18 + lucide, слои руками (как в 1.3.0) | 46,6 КБ | — | 0,4 КБ |
| `prim-dialog` | `@radix-ui/react-dialog` 1.1.23 | 58,8 КБ | **+12,2 КБ** | 0,4 КБ |
| `primitives` | Dialog + Popover + Toast + Tooltip | 78,9 КБ | **+32,3 КБ** | 0,4 КБ |
| `prim-select` | один `@radix-ui/react-select` 2.3.7 | 75,9 КБ | +29,3 КБ | 0,4 КБ |
| `prim-avatar` | один `@radix-ui/react-avatar` 1.2.6 | 48,6 КБ | +2,0 КБ | 0,4 КБ |
| `shadcn` | Dialog + Popover + Select + Slot + cva + clsx + tailwind-merge + Tailwind 4.3.3 | 87,7 КБ | +41,1 КБ | 3,1 КБ (12 КБ) |
| `themes` | `@radix-ui/themes` 3.3.0: Theme, Button, Dialog, Popover, Select, TextField, Badge | 89,0 КБ | +42,4 КБ | **81,9 КБ (695 КБ)** |

Для масштаба: весь текущий бандл Schoolium 1.3.0 — 160,1 КБ gzip JS + 26,9 КБ gzip
CSS (`index-B68Xx8iW.js`, `index-CeHufslL.css`, сборка от 2026-09-03). CSS одной
`@radix-ui/themes` в три раза больше всего CSS приложения.

## 2. Критерии

| Критерий | (а) `@radix-ui/themes` | (б) Radix + shadcn/ui (Tailwind) | (в) Radix Primitives + стили на токенах |
|---|---|---|---|
| Доступность из коробки (фокус, клавиатура, aria) | да — те же примитивы под капотом | да — те же примитивы | да: `Dialog` даёт `role="dialog"`, `aria-modal`, `aria-labelledby`, ловушку и возврат фокуса, `Esc`, клик мимо, блокировку прокрутки; `FocusScope` перефокусирует контейнер при удалении сфокусированного узла (`MutationObserver`) — тот самый дефект, который 1.3.0 чинила руками |
| Модалки и поповеры с фокус-ловушкой | да | да | да; `Popover.Anchor virtualRef` принимает `DOMRect`-якорь — контракт `anchor: DOMRect` экранов сохраняется |
| Мобильные листы | нет своего компонента: `Dialog` + свой CSS | нет (в shadcn это `vaul`, ещё одна зависимость) | `Dialog` + наш `data-shape="sheet"` и свайп (как в 1.3.0) |
| Размер бандла (gzip) | +42,4 КБ JS **+81,9 КБ CSS** | +41,1 КБ JS + 3,1 КБ CSS + тулчейн Tailwind в сборке | **+32,3 КБ JS**, CSS 0 |
| G-37: цвета только из токенов | **нет**: своя палитра 12-ступенчатыми шкалами (`--violet-9` = `#6e56cf`, токен `violet-700` = `#6427C9`), 1555 hex-литералов в `styles.css`; чтобы завести цвет из `tokens.json`, пришлось бы генерировать 12 ступеней на каждый оттенок и переопределять переменные Themes | **нет**: утилиты палитры (`text-red-600`, `bg-black/60`) дают цвет ни литералом, ни токеном — сканер G-37 их не видит; собранный CSS несёт `oklch(...)`-литералы палитры Tailwind | **да**: библиотека не несёт ни одного правила CSS, цвет остаётся в `tokens.css` |
| G-83: иконки только `lucide` через `Icon` | **нет**: `Select`/`Dialog.Close` рисуют свои SVG (`components/icons.js`) | да (иконки передаются снаружи) | да (примитивы иконок не рендерят) |
| Совпадение со шкалами `tokens.json` (шрифт, радиус, отступ) | **нет**: своя шкала `--font-size-1…9` (12/14/16/18/20/24/28/35/60) и `--radius-factor` | своя шкала Tailwind (rem-ступени), настраивается через `@theme` | шкалы — только наши переменные |
| Второй язык стилей рядом с `app.css` (AR-43) | да: классы `rt-*` и пропсы `size`/`color`/`radius` | **да**: Tailwind-утилиты рядом с 1200 строками `app.css` и 8600 строками экранов на `sch-*` | нет |
| Сохранение `data-testid` (G-52) | да, пропсы прокидываются | да | да |

## 3. Вывод

Принят вариант (в): Radix Primitives как headless-слой (`react-dialog`,
`react-popover`, `react-toast`, `react-tooltip`; плюс `react-avatar` за 2,0 КБ —
инициалы до загрузки фото и при битой ссылке), стили — наши, на переменных из
`tokens.json`. Единственный вариант, при котором G-37 и G-83 продолжают что-то
доказывать, а бандл растёт на ~32 КБ gzip, не на ~124.

`<select>` остаётся нативным: `@radix-ui/react-select` стоит +29,3 КБ gzip ради
выпадашки, которую телефон рисует системной, а смок обращается к нему через
`selectOption`.
