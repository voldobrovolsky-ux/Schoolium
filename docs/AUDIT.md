## 1. Пять главных фич

Ранжир по «сила боли × число тех, кому больно».

| # | Фича | Почему купят |
|---|------|--------------|
| 🥇 | **Авторасписание (Solver + Forecast)** | Недели ручного ада завуча + штрафы за СанПиН/недобор часов. Painkiller. Якорь продажи №1, высокий switching cost. |
| 🥈 | **Голосовой ввод оценок** | Продаёт за 30 секунд на демо. Ежедневная ценность для самого массового пользователя (учитель). Дёшево, высокий воспринимаемый эффект. |
| 🥉 | **Кабинеты специалистов (психолог)** | У психолога сегодня нет инструмента (Excel/бумага). Отдельный SKU, расширяет рынок за пределы «школа купила LMS». |
| 4 | **Родительский портал с оплатами** | Родитель — плательщик и политическая сила. «Оценки + посещаемость + оплата питания/студий» в одном окне = retention + меньше жалоб директору. |
| 5 | **Предиктивная аналитика + risk-карта** | Нарратив «EduStore думает за вас». Главный ответ на «чем вы лучше Дневник.ру». Мост учитель→специалист. |

> Studio CRM + QR, Платформа курсов, Union — драйверы **экосистемы и сетевого
> эффекта**, не первой продажи одной школе.

## 2. Новые фичи

Критерии: реализуемо, защитимо 2–3 года, бьёт в боль, продаёт.

1. **Curriculum Guarantee** — программа как burn-down часов: «7Б недоберёт 14 ч
   по алгебре из-за праздников — вот 3 сценария добора». Никто не моделирует
   программу как ресурсно-временной план с прогнозом дефицита. Реализация:
   DAG тем × нормо-часы → факт из журнала → линейная экстраполяция (не ML).
2. **Голосовой журнал целиком** — «Иванову пять, Петров отсутствовал, ДЗ §12» →
   оценки + посещаемость + замечания + ДЗ. Whisper + structured extraction.
3. **Мост «бумага → цифра»** — фото тетради по QR-маркеру бланка → авто-привязка
   к ученику/заданию + предпроверка типовых. 90% работ в РФ-школе на бумаге.
4. **Explainable risk + «маршрут помощи»** — каждый сигнал объясним, доступ
   разграничен (учитель не видит score), из сигнала запускается кейс. Намеренно
   rule-based (юридически защитимее под 152-ФЗ).
5. **Verified Methodist Marketplace** — биржа верифицированных методистов; школа
   из глубинки подключает куратора на несколько школ. Решает кадровый голод.
6. **«GitHub для уроков»** — fork/версии/рейтинг курсов по реальному
   использованию. Банки контента статичны; fork/merge нет ни у кого.
7. **Граф нагрузки ребёнка** — единый граф через `florus_user_id`: «6 кружков +
   3 продлёнки = риск перегруза». Уникальный родительский инсайт.

Флагманы под сроки: **2.1 (Curriculum Guarantee)** и **2.4 (explainable risk)** —
дёшевы (rule-based), бьют в боль директора/надзора.

## 3. Сложности и решения (80/20)

Сквозной принцип: не строить тяжёлый движок — взять готовое, дать тонкую версию,
разделить ответственности.

| Элемент | Главная сложность | Решение 80/20 |
|---|---|---|
| Авторасписание | NP-трудный CSP; 80% провалов — грязные данные + бунт учителей | OR-Tools CP-SAT; типовая неделя, не год; solver = ассистент завуча (80% авто, конфликты вручную) |
| Голосовой ввод | Падежи фамилий, шум, однофамильцы, цена ошибки | Constrained vocab = список класса; faster-whisper CPU; обязательный визуальный confirm в 1 тап |
| Кабинеты | Соблазн 6 продуктов; конфиденциальность | Один generic case-management + конфиг на кабинет; к старту — только психолог; ABAC + приватные заметки |
| Union | Соблазн федерации; протечка ПД | v1 = оргструктура + обезличенные агрегаты; сырые данные учеников не ходят |
| Платформа курсов | Модерация, права, версионирование | Библиотека (fork = глубокая копия), рейтинг = звёзды+счётчик, модерация постфактум |
| Методисты | Что такое «эксперт», оплата, налоги | Верификация v1 = ручная (бейдж); мультишкольность бесплатно от RBAC; оплата вне платформы |
| QR-подключение | Безопасность, согласие, идемпотентность | Короткоживущий подписанный one-time токен → PENDING → двусторонний хендшейк |
| Биллинг | Соблазн self-service платёжки к старту | Разделить: школам — entitlements + счёт вручную; родителям — эквайринг (ЮKassa) |
| Предиктив | Соблазн ML без данных; чёрный ящик для детей | Не ML. Прозрачные правила, объяснимо, работает с нулём истории |

## 4. Архитектура

**Вердикт:** стек правильный по форме, но переинженерён для «один фаундер + 11
недель». Сохранить форму, вырезать ops-тяжёлое.

| Компонент | Решение | Почему |
|---|---|---|
| NestJS + TS modulith | ✅ ОСТАВИТЬ | Один язык с Communitoria/Flōr Office; Nx-монорепо + eslint-boundaries |
| Keycloak | ✅ ОСТАВИТЬ | Брокер ЕСИА+Flōrus, не писать свой OIDC |
| Postgres + RLS | ✅ ОСТАВИТЬ | RLS как defense-in-depth + скоупинг в приложении |
| Transactional outbox | ✅ ОСТАВИТЬ | Нересретрофитимый фундамент событий |
| NATS | ✅ ОСТАВИТЬ | Лёгкий; Kafka не добавлять до объёма |
| OPA/Cerbos | 🟡 УПРОСТИТЬ | roles-as-data в самом NestJS; отдельный policy-сервис позже |
| Module Federation | 🟡 ОТЛОЖИТЬ | Standalone-кабинет = модульный код + entitlement-гейтинг, не MF в рантайме |
| Python ML | 🟡 ОТЛОЖИТЬ | Предиктив v1 = правила в NestJS |
| Kubernetes + Terraform | 🔴 ВЫРЕЗАТЬ из v1 | Для соло — time-sink; 1–2 VM + compose / managed |
| ClickHouse | 🔴 ВЫРЕЗАТЬ из v1 | Нет объёма; правила в Postgres |
| OpenSearch | 🔴 ВЫРЕЗАТЬ из v1 | Postgres FTS закрывает старт |
| React Native | 🔴 ОТЛОЖИТЬ | v1 = адаптивный веб/PWA |
| Whisper (faster-whisper) | ✅ ОСТАВИТЬ | Единственный оправданный Python-сервис v1; CPU |

Рантайм v1 ≈ 5 коробок: NestJS · managed Postgres · Redis · NATS · Whisper.

## 5. Серверы и инфраструктура

> Реальные тарифы Yandex Cloud 2025–2026, ex-VAT. НДС с 01.01.2026 = 22%
> (gross = ×1.22). Якорь: vCPU@100% = 1,1529 ₽/ядро·ч; RAM = 0,3074 ₽/ГБ·ч.

**Рефрейм:** это мультитенантный SaaS — школы делят инфру, маржинальная стоимость
школы мала. Выделенные ресурсы — только Enterprise по требованию изоляции.

Профиль нагрузки (≈ ученики × 1.65 юзеров; пик ~15% concurrent):

| Учеников | Юзеров | Пик conc. | DB/год | Файлы/год | Марж. инфра ₽/мес |
|---|---|---|---|---|---|
| 100 | ~165 | ~25 | ~0.5–1 ГБ | ~10–30 ГБ | ~300–600 |
| 500 | ~825 | ~125 | ~2–4 ГБ | ~50–150 ГБ | ~1 000–2 000 |
| 1000 | ~1650 | ~250 | ~5–10 ГБ | ~100–300 ГБ | ~2 000–4 000 |
| 2000 | ~3300 | ~500 | ~10–20 ГБ | ~200–600 ГБ | ~4 000–7 000 |

Один инстанс NestJS 2vCPU/4GB ≈ 200–600 RPS → даже школа 2000 укладывается в
1 инстанс на пике; деньги — в БД (PgBouncer от тысяч юзеров), не в app-ноды.

Стоимость по стадиям (incl 22% НДС):

| Стадия | Кого тянет | ₽/мес |
|---|---|---|
| Dev | — | ~12 000–15 000 |
| Пилот (1–5 школ) | 1 VM 8/32 + PG single | ~18 000–25 000 |
| Продакшн (5–50 школ, 10–50k юзеров) | 2× app + PG HA + Redis + NATS + Whisper + Keycloak + ALB | ~50 000–67 000 |
| Масштаб (50–300 школ) | K8s + автоскейл + PG-реплики + ClickHouse | ~200 000–500 000+ |

**Экономия:** (1) self-host Redis на VM (~2 200 ₽) вместо managed HA (~18 200 ₽) →
−16k/мес; (2) **GPU не нужен** — faster-whisper int8 на CPU (короткая фраза
суб-секунда; T4 24/7 ≈ 610k ₽/мес — разорительно). Пропуск ClickHouse + self-host
Redis = −35k/мес.

Когда single→cluster: (а) >1 платящая школа зависит от аптайма (HA), (б) пик
concurrent ~2–3k на инстанс, (в) нужны zero-downtime деплои. K8s — на ~50+ школах.

Подробно: [INFRA.md](./INFRA.md).

## 8. Стратегия продаж

**Воронка:** Частные школы (вне 44-ФЗ) → отдельные муниципальные (единственный
поставщик) → централизованный контракт региона.

**Champions:** завуч (боль расписания) + директор (родители+надзор) + учитель
информатики (евангелист голоса).

**Обход тендеров законно:**
- Частная школа — **44-ФЗ не применяется** (первый контракт уже здесь).
- Муниципальная: **контракт ≤ 600 000 ₽ → единственный поставщик** (ст.93 ч.1
  п.4/п.5; для образования годовой лимит до 5 млн ₽). Модули = отдельные
  контракты ≤600k (анти-«дробление» разрешено).
- Держаться ниже «крупной сделки» (>10% активов).
- Снять трение: готовый КП+договор+обоснование + **реестр ПО** = «безопасный
  российский выбор». Заходить осенью (верстка ПФХД).

**Beachhead:** авторасписание (острейшая боль, чемпион-завуч) → land-and-expand.

**Freemium не работает для школ** → бесплатный пилот на семестр → ROI → платный.

**Union как канал:** рейтинги + общий контент = FOMO; верифицированный методист на
несколько школ сшивает их в сеть.

**Позиционирование:** не замена гос-журналу, а надстройка. Щит и меч —
**«для родителей бесплатно навсегда»** (на попутном политическом ветре против
платных дневников).

## 9. Ключевые поправки

1. **ГИС-ограничение (273-ФЗ ст.16 ч.3.1)** — журнал EduStore: полный для частных
   школ; для госшкол — синк в гос-ГИС, продавать не-журнальные модули (зелёная
   зона: расписание, кабинеты, аналитика, портал, контент).
2. **Реальные тарифы YC** подтвердили модель (пилот ~20–35k, продакшн ~50–67k ₽/мес;
   Redis self-host и без GPU — экономия).
3. **Декабрь 2025: Госдума против платных дневников** — попутный ветер для «бесплатно
   родителям»; красная линия: никогда не paywall оценки/ДЗ и без рекламы в детском
   интерфейсе (ФАС штрафует — кейс ЭлЖур).
