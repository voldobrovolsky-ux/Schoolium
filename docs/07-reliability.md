# Reliability

| SLI | Definition | Target | Window | Error budget |
|---|---|---|---|---|
| Login completion | completed valid OIDC login flows / initiated valid flows | To be accepted | 28 days | To be accepted |
| Workspace authorization latency | requests completing within target | To be accepted | 28 days | To be accepted |
| Identity-event convergence | delivered IDP events applied within target | To be accepted | 28 days | To be accepted |

Targets are intentionally not invented: capacity, user impact, and dependency budget need product-owner approval. The IDP's proposed targets are recorded in `IDP-SPEC.md`.
