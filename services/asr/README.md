# EduStore ASR — голосовой ввод оценок

Микросервис распознавания речи (RU) для функции голосового выставления оценок
в кабинете учителя. Учитель диктует короткую реплику — например, **«пять
Иванову»** — сервис возвращает текст, который фронтенд превращает в оценку.

## Стек
- **FastAPI + uvicorn** — HTTP API.
- **faster-whisper (CTranslate2)** — распознавание, CPU-only, квантизация
  **int8**. Для коротких клипов (до ~2 сек) латентность ожидается субсекундной.
- Размер модели берётся из переменной окружения `ASR_MODEL` (по умолчанию
  `small`).

## Запуск (dev)

```bash
cd services/asr
pip install -r requirements.txt
cp .env.example .env            # при необходимости поправьте ASR_MODEL / ASR_MOCK
uvicorn main:app --reload --port 8001
```

Сервис поднимется на http://localhost:8001.

### Docker

```bash
docker build -t edustore-asr .
docker run -p 8001:8001 -e ASR_MODEL=small edustore-asr
```

## API

### `GET /health`
```json
{ "status": "ok", "model": "small", "mock": false }
```

### `POST /transcribe`
Запрос:
```json
{
  "audio_base64": "<base64 байтов wav/webm/ogg/mp3>",
  "vocabulary": ["Иванов", "Иванов Артём", "Петрова Мария"]
}
```
Ответ:
```json
{ "text": "пять Иванову", "confidence": 0.92, "language": "ru" }
```

- Распознавание идёт с `language="ru"`, `beam_size=5`.
- **Биасинг под словарь класса:** из `vocabulary` (ростер класса) собирается
  короткий `initial_prompt` (имена через запятую) — модель «праймится» под
  ограниченный словарь (constrained-vocabulary biasing), что повышает точность
  распознавания фамилий.
- `confidence` — значение 0..1, выводится из `avg_logprob` сегментов через
  `exp()` со штрафом на `no_speech_prob`.
- Модель загружается **лениво один раз** (module-level singleton) и
  переиспользуется между запросами.

Пример:
```bash
curl -s http://localhost:8001/transcribe \
  -H 'Content-Type: application/json' \
  -d '{"audio_base64":"<...>","vocabulary":["Иванов","Петрова"]}'
```

## Mock-режим (для dev/CI и демо без скачивания модели)

Модель faster-whisper весит несколько гигабайт и скачивается при первом
запуске. Чтобы сервис работал в CI/песочнице/демо **без** загрузки модели,
включите mock-режим:

```bash
ASR_MOCK=1 uvicorn main:app --port 8001
```

В mock-режиме:
- модель **не загружается**, импорт faster-whisper не требуется;
- `/health` возвращает `"mock": true`;
- `/transcribe` отдаёт детерминированный ответ:
  `{ "text": "пять Иванову", "confidence": 0.92, "language": "ru" }`.

Mock включается также **автоматически**, если faster-whisper не установлен или
модель не удалось загрузить (мягкая деградация) — сервис всё равно стартует и
отвечает на `/health`.

## Скачивание модели

При первом реальном запуске (`ASR_MOCK=0`) faster-whisper скачивает веса с
Hugging Face в кеш (`~/.cache/huggingface`). Это требует доступа в интернет и
несколько ГБ места. В монорепо каталог `services/asr/models/` добавлен в
`.gitignore`. Для офлайн-окружений модель можно предварительно скачать и
смонтировать том с кешем.

## Мягкая деградация
Сервис спроектирован так, что недоступность ASR не ломает систему: фронтенд
продолжает работать с ручным вводом оценок, а сам сервис при проблемах с
моделью переходит в mock-режим вместо падения.
