# С4д · Дизайн-спека 1.1.1 (Schoolium, десктоп + мобайл)

> Направление владельца: фиолетово-розовая гамма с обилием белого (AR-80).
> Токены: [docs/design/tokens.json](../../docs/design/tokens.json) — контраст
> каждой пары доказан G-37 (`node tools/design/check-contrast.mjs`, 21 пара).
> Экраны сверены с матрицей FSM `30-spec.md`: у каждого состояния — дом; этот
> документ добавляет пустые состояния (закрывает остаток линзы L-14).
> Документ передаётся в окно генерации кода как единственный источник
> визуального слоя.

## 1. Принципы

1. **Белый — материал, фиолетовый — структура, розовый — действие-акцент.**
   Страница белая (`surface.page`), секции — едва-фиолетовая канва
   (`surface.canvas`, `violet-050`); первичные действия — `violet-700`,
   ключевой акцент шага (QR, «сгенерировать») — `pink-600`. На экране не
   больше одного розового элемента одновременно.
2. **Правило разведения розовых** (AR-80): брендовый розовый — только
   интерактив; пастель `sex.girl-bg` — только заливка строк журнала
   контингента. Эти два розовых не встречаются на одном экране в одной роли.
3. **Смысл не кодируется одним цветом**: отметки несут символ (5, 4, 3, 2, н,
   б) на цветной подложке; маркеры пола — заливка строки при наличии текста;
   состояния — иконка + текст, не только оттенок.
4. **Карточка — базовая единица** (AR-77): сетка карточек → тап → блюр фона
   `overlay-blur` + карточка в центре, радиус `radius.card` (20), тень
   `shadow.modal`. Один паттерн на классы, предметы, персонал.
5. **Тап-мишени ≥44px** (`tap.minTargetPx`) — модератор работает и с телефона.

## 2. Типографика и сетка

| Роль | Шрифт | Размер/начертание |
|---|---|---|
| Заголовок экрана | Manrope | h1 34 bold (моб. 28) |
| Заголовок карточки | Manrope | xl 22 semibold |
| Текст | Inter | md 16 regular |
| Вторичный/подписи | Inter | sm 14 regular, `ink.secondary` |
| Ячейка журнала | Inter | sm 14 medium, табличные цифры |

Десктоп: контент 1200px, сетка 12 колонок, gutter 24. Карточки классов — 4 в
ряд (280px), предметов — 3 в ряд. Мобайл: одна колонка, карточки во всю ширину,
нижняя таб-навигация: Классы · Предметы · Персонал · Расписание · Журнал.
Отступы — только из `space.scale`.

## 4. Экраны (дом каждого состояния FSM + пустые состояния)

### Вход (после онбординга)
Белый экран, логотип Schoolium (градиент violet-600→pink-500 только в
логотипе), поле телефона, primary «получить код», экран OTP из 4 ячеек.
Ошибка шлюза: карточка «вход временно недоступен, обратитесь к модератору»
(спека, деградация SMS). Пустое состояние не нужно — экран одноцелевой.

### Классы
Пусто (`empty`): контур-иллюстрация, «Классов пока нет», primary «создать
классы» → мастер. Заполнено: сетка карточек «5 класс» / «5А», подзаголовок
«15 учеников · 2 группы», прогресс заполнения профилей тонкой полосой
`violet-500`. Карточка класса (открытая): журнал контингента — строки с
заливкой `sex.boy-bg`/`sex.girl-bg`, пустой профиль — пунктирная строка
«тапните, чтобы заполнить»; под таблицей кнопки «добавить ученика»,
«редактировать», «удалить» (danger-текст; для ученика с отметками — заменяется
на «деактивировать», AR-78).

### Мастер классов (модалка, 5 шагов)
Прогресс-точки сверху (заполненная — `violet-700`). Шаг литер: сегмент-выбор
А…Д + кнопка-отказ «без литер». Шаг пола: одно поле + строка-вывод «девочек:
6 — посчитано автоматически» (`ink.secondary`). Финал: превью «будет создано
8 классов: 1, 2, … 8» на канве `violet-050`, primary «создать» (Д5).

### Предметы
Пусто: «Предметы появятся после классов» + primary «создать предмет» (активна
только из состояния `students_filled`+). Карточка: название, класс, аватары
привязанных педагогов в правом верхнем углу, «+» — QR-привязка (accent).
Открытая карточка с QR: после скана — выбор «весь класс» / чипы групп;
непокрытая группа — чип с рамкой `state.warning` и подписью «нет педагога».

### Персонал
Пусто: «Активируйте персонал» + primary «активация персонала». Три уровня
секциями на канве: «Учредители и директор», «Заместители», «Преподаватели»;
«добавить» — только у множественных ролей (AR-60). Карточка до активации —
замок; открытая — QR-панель; после — имя, роли бейджами `violet-100`, кнопка
«добавить роль». Регистрация на телефоне сотрудника: два поля (ФИО, телефон),
затем экран фото: круг-плейсхолдер + «прикрепить фото» / secondary «продолжить».

### Расписание
До настройки (пусто): «Расписание появится после настройки» + primary
«настроить» (активна из `teachers_bound`). Модалка 4 экранов: 1 — четыре
панели четвертей (заполненная — галочка `state.success`), предзаполнены ФООП;
2 — аккордеон педагогов, подписанные окошки часов («математика · 5 класс»),
ошибки сумм — под аккордеоном с именем класса и цифрами; 3 — чипы приоритетных
предметов + кнопка-отказ «без приоритетов»; 4 — параметры дня, при нарушении
СанПиН текст нормы под полем. Генерация: полноэкранный прогресс на белом с
логотипом; отказ — карточка с кодом, человекочитаемой причиной и кнопкой «к
шагу N». Предпросмотр (`generated`): сетка неделя × классы, спаренные
групповые часы — разделённая по диагонали ячейка; снизу secondary
«регенерировать» + primary «подтвердить». `stale` — плашка сверху экрана.

### Журнал (`ready`, терминал)
Слева — вертикальный список ФИО (заливки пола), сверху — даты; два урока в
дату — две колонки под одним числом со скобкой. Будущие колонки — текст
`disabled-ink`, заливка `disabled-bg`, тап даёт тост «урок ещё не прошёл»
(гейт — контракт, UI отражает). Тап по числу — поповер темы: поле + primary
«сохранить». Ячейка — чип отметки; выбор — шесть чипов в ряд (5 4 3 2 н б).
Пусто (нет материализованных уроков): «Уроки появятся после подтверждения
расписания» со ссылкой на экран расписания.

### Кабинет модератора
Виден только модератору (AR-69): те же экраны в режиме ведения + журнал
аудита своих действий (список, без фильтров в 1.1.1).

## 5. Мобайл-особенности

> Полная раскладка обеих версий — оболочка, реестр модалок, реестр кнопок,
> матрица состояний — вынесена в [75-adaptive.md](./75-adaptive.md) (ворота G-39).
> Ниже — краткая сводка.

Журнал: список ФИО закреплён слева (сокращается до «Иванов И.»), колонки дат
скроллятся горизонтально; чипы отметок — нижний лист (bottom sheet) вместо
поповера. Мастера — полноэкранные шаги вместо модалок. QR-скан педагога — по
значку сканера в шапке личного кабинета (камера). Таб-бар скрывается в
модальных потоках.

## 6. Что НЕ входит
Тёмная тема (слот; токены заведены парами «ink × surface», инверсия ляжет на
них); анимации сложнее fade/scale 150мс; кастомные иллюстрации (в 1.1.1 —
контурные плейсхолдеры `violet-100`); печатные формы.

## 7. Критерии готовности
- Когда каждый экран §4 свёрстан в обоих раскладках и каждое состояние FSM
  находит свой дом визуально — этап закрыт (сверка по матрице `30-spec.md`).
- Когда `node tools/design/check-contrast.mjs` зелёный на финальных токенах —
  этап закрыт (G-37).
- Когда пустое состояние каждого экрана ведёт одной кнопкой к следующему шагу
  онбординга — этап закрыт (линза L-14).
