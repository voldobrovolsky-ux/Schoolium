# Исполняемая модель (T2)

Одноразовый код: без БД, без фреймворка, без сети. Задача — сломать спеку.

- `states.mjs` — состояния, переходы, терминалы, роли (данные, не код)
- `walk.mjs` — обход перечислением: недостижимые, тупики, путь к терминалу
- `props.mjs` — инварианты на случайных последовательностях + минимизация контрпримера
- `sim.mjs` — день школы: касания, минуты, переключения контекста

Прогон: `node specs/<id>/model/walk.mjs && node specs/<id>/model/props.mjs && node specs/<id>/model/sim.mjs`
