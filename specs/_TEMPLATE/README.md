# Шаблон папки задачи

Копируется как `specs/<короткий-id>/`. Файлы заполняются по стадиям конвейера
([PIPELINE.md](../../docs/method/PIPELINE.md)); каждый — ворота следующей стадии.

| Файл | Стадия | Ворота |
|---|---|---|
| `00-request.md` | С0 приём | границы записаны, «не входит» непустое, блокирующих вопросов ≤1 |
| `10-basis.md` | С1 базис | каждая строка со ссылкой и классом обязательности |
| `20-fit.md` | С2 проекция | ни одного требования класса `закон` без исхода; конфликты разрешены |
| `30-spec.md` | С4 спека | `node tools/method/spec-lint.mjs` зелёный (P1…P7) |
| `model/` + `40-bench.md` | С5 стенд | сценарии исполнены, есть раздел «что стенд не ловит» |
| `50-lens-report.md` | С6 линзы | ни одной красной линзы без правки или `[узел]` с владельцем |

Решения (стадия С3) живут не здесь, а в `docs/ar/<блок>.md` — спека на них ссылается.
